# FlowMind 1.5.2

FlowMind 1.5.2 closes the last manual step in the workflow sync path: when local `auto-flow` learning data exists, `flowmind resource --sync-sdd-agent` now seeds the workflow MCP binding automatically.

## Highlights

- Imported workflow knowledge from local `auto-flow` learning data
- Wrote a `workflow` resource entry into FlowMind local config
- Wrote a `workflow` component config so `auto-flow` can resolve `auto-flow` without manual setup
- Preserved the previously shipped AI-less and passive-learning behavior

## Verification

- Ran targeted regression suites for sync helpers and skill routing: `17/17` passing
- Verified a temp sync run creates workflow bindings, workflow resource config, and workflow component config
- Published npm package: `flowmind@1.5.2`

## Try It

```bash
flowmind resource --sync-sdd-agent
flowmind resource
flowmind "自动部署 uat-retail-takeout-manager"
```
