# FlowMind 1.5.14

FlowMind 1.5.14 tightens the SLS and trace-query experience so default answers show the actual final service return, while detailed views expose every parsed downstream response.

## Highlights

- Default `log-audit` and `sls-log-audit` summaries now show the final downstream service response body instead of only status placeholders
- Trace anomaly summaries now surface up to the first three exception lines when an error is present
- Detailed `more` and `full` views now include a parsed `服务返回` section for every service in the chain
- Response parsing now handles bracketed Feign return lines and avoids misclassifying structured success payloads as exceptions
