# FlowMind 1.5.1

FlowMind 1.5.1 is a release-note and packaging update that makes the AI-less usage story explicit: even without an AI model, accumulated local knowledge still keeps MCP and learned-binding workflows usable.

## Highlights

- Clarified the no-AI workflow path for users who only want local knowledge plus MCP execution
- Confirmed that binding-style requests still resolve to `resource-bind` without requiring an AI provider
- Kept the previously shipped CLI, TUI, sync, and passive-learning improvements intact

## Verification

- Ran a smoke test with no AI provider configured
- Confirmed `FlowMind.hasAI()` returned `false`
- Confirmed a binding-style request still executed through `resource-bind`
- Published npm package: `flowmind@1.5.1`

## Try It

```bash
flowmind "绑定发布平台 mcp=auto-flow token=xxx env=uat"
flowmind resource
flowmind ai --status
```
