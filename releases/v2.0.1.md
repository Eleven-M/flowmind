# FlowMind 2.0.1

FlowMind 2.0.1 completes the 2.0 upgrade maintenance pass by aligning release metadata with the package version and making guarded workflow resume available from the CLI path as well as MCP.

## Highlights

- CLI workflow executions are now persisted to the local workflow history store.
- `flowmind workflow-history` lists recent recorded guarded workflow executions.
- `flowmind workflow-resume --execution-id <id> --approval-token <token>` resumes a recorded workflow from the first unfinished step.
- Release maintenance files now target `flowmind@2.0.1`.

## Safety

- Workflow execution still requires the approval token produced by the reviewed dry-run.
- Stored workflow history excludes approval tokens from public history output.
- Resume reuses the recorded workflow chain instead of accepting an unreviewed replacement chain.

## Verification

- `npm test -- --runInBand`
- `node bin/flowmind.js release-check --json`
- `node bin/flowmind.js upgrade-status --json`

## Upgrade Status

- Current npm target: `flowmind@2.0.1`
- Multi-cloud governance remains available through the local skill surface.
- Guarded workflow execution history is persisted locally through MCP and CLI.
- Provider-specific rollback previews remain available before guarded governance execution.
