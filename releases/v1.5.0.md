# FlowMind 1.5.0

FlowMind 1.5.0 makes local workflow memory materially more useful: it can import an existing `sdd-agent` setup, reuse repeated resource choices without explicit feedback every time, accept direct binding commands from the CLI without extra ceremony, and keep repeated MCP workflows useful even when no AI model is configured.

## Highlights

- Added `resource --sync-sdd-agent` to copy local `sdd-agent` resources, bindings, scenes, and component state into FlowMind
- Added two passive learning enhancements:
  - repeated resource-binding success can promote a preferred binding for the relevant skill/component
  - repeated successful scene execution can promote a reusable default scene preference
- Added a practical MCP-only path: once local bindings and scene knowledge are accumulated, FlowMind can keep reusing that knowledge without depending on an AI model for every run
- Improved CLI ergonomics so `flowmind "..."` runs as a normal request and binding-style prompts route to `resource-bind` correctly
- Fixed config bootstrapping so a fresh local setup no longer emits a false missing-version warning
- Published the CLI/TUI host-safety fix so managed Codex or Claude-style terminals do not get destabilized by nested fullscreen startup

## What Changed

- New local sync path from `~/.sdd-agent` into `~/.flowmind`
- New passive learning persistence for auto-generated preferences under `learning/records/*`
- New resource overview and sync summary output for `flowmind resource`
- Better intent routing for prompts like `绑定发布平台 mcp=auto-flow token=xxx env=uat`
- Better fallback value from accumulated knowledge in MCP-only usage, where previously learned bindings and scenes remain directly reusable

## Verification

- Re-ran targeted regression suites for routing, config loading, sync import, and passive learning: `24/24` passing
- Verified `resource --sync-sdd-agent` against both a temporary FlowMind home and the real local FlowMind home
- Verified passive promotion writes local preference records after repeated successful runs
- Published npm package: `flowmind@1.5.0`

## Try It

```bash
flowmind resource --sync-sdd-agent
flowmind resource
flowmind "绑定发布业务 mcp=auto-flow token=xxx env=uat"
flowmind process --skill yapi-sync-interface "同步接口到 yapi"
```
