# FlowMind 1.5.13

FlowMind 1.5.13 completes the current upgrade wave around MCP platformization, structured skill contracts, reporting, knowledge operations, data risk audit, and change impact review.

## Highlights

- Added the upgraded MCP capability surface, including capability catalog discovery and async task status tools
- Added the report skill family for build, test, and coverage summaries
- Added knowledge operations for search, list, save, update, and runbook template flows
- Added data risk audit for SQL and Redis risk detection, with optional database metadata and EXPLAIN previews
- Added change impact review that classifies changed files, regression scope, sync recommendations, and follow-up automation candidates
- Standardized retry hints, binding hints, automation candidates, next actions, and skill-level error envelopes for upgraded flows
