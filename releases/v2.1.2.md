# FlowMind 2.1.2

FlowMind 2.1.2 fixes WorkBuddy MCP compatibility for strict tool schema validation.

## Fixed

- `flowmind-mcp` no longer returns `outputSchema: null` for skills that do not declare an output schema.
- MCP `tools/list` now omits undeclared `outputSchema` fields and only includes object schemas.
- Dynamic skill tools now read full skill definitions so declared object schemas are still exposed correctly.

## Verification

```bash
npm test -- --runInBand __tests__/upgrade-skills-and-mcp.test.js
npm run package:check
npm pack --dry-run
```

## Upgrade Status

- npm target: `flowmind@2.1.2`
- WorkBuddy users should restart WorkBuddy after upgrading so it reloads the FlowMind MCP server metadata.
