# FlowMind 2.0.4

FlowMind 2.0.4 improves natural-language skill routing, no-model analysis, and runtime readiness visibility.

## Highlights

- Added deterministic local analysis for synchronized learning records, Markdown/HTML/Lake/Lakebook documents, and repository code when no AI model is available.
- Added evidence-backed design flows, document/code summaries, confidence, limitations, and test-focus output through skill, CLI, and MCP entry points.
- Added persistent request-to-skill route learning after explicit CLI/runtime selection or conversational correction.
- Added TUI readiness markers for skills, MCP components, Git context, explicit configuration, disabled skills, and exact missing bindings.
- Distinguished business-flow analysis from workflow execution so broad `流程` wording does not route to `auto-flow`.
- Reserved `offline-design-analysis` for no-model sessions or explicit offline execution so model-backed analysis is not intercepted.

## Safety and Compatibility

- Offline analysis does not call a model or network service and never executes analyzed code.
- Archive traversal, generated/vendor paths, binary files, oversized input, and credential-like values are guarded or redacted.
- Learned fuzzy routes require the same action family and a conservative similarity threshold.
- MCP readiness displayed in the TUI is a local configuration check and does not run remote health probes during rendering.
- Runtime support remains Node.js 18 and newer.

## Verification

- `npm run quality`
- `npm pack --dry-run`
- Official skill validation for updated skills
- Real configured-provider routing check for model-backed analysis

## Upgrade Status

- npm target: `flowmind@2.0.4`
- Existing local configuration and learning bundles remain compatible.
- Restart a running TUI after upgrading so Node.js reloads the updated routing modules.
