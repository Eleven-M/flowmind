# FlowMind 2.3.1

FlowMind 2.3.1 introduces the Jev decision provider for feature-level skill routing. Jev is a typed decision provider, not a general chat model: it is registered dormant by default and only participates after explicit enablement.

## Added

- Built-in `jev` decision provider for structured skill-selection decisions with confidence and probability output.
- `featureProviders.skillSelection` routing so a decision feature can use Jev while generic chat and completion calls continue using the default LLM provider.
- Automatic fallback to the default provider when Jev is disabled, unavailable, fails, or returns confidence below the configured threshold.
- Doctor and AI status reporting for disabled decision providers, including the reason they are not active.

## Configuration

Jev remains inactive until both explicit enablement and an API key are present:

```json
{
  "ai": {
    "providers": {
      "jev": {
        "enabled": true,
        "apiKey": "${JEV_API_KEY}",
        "model": "jev-latest"
      }
    },
    "featureProviders": {
      "skillSelection": "jev"
    }
  }
}
```

See [docs/provider-adapter-guide.md](../docs/provider-adapter-guide.md) for the decision-provider contract.
