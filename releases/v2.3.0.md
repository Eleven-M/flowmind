# FlowMind 2.3.0

FlowMind 2.3.0 introduces a read-only Ontology P0 inventory, giving structured visibility into skills, components, resources, MCP servers, result contracts, and entity storage statistics.

## Added

- Read-only Ontology P0 inventory covering skills, components, resources, MCP servers, result contracts, and entity storage statistics.
- `flowmind ontology inventory` CLI subcommand for querying the inventory.
- `flowmind ontology validate` CLI subcommand for validating inventory consistency.
- `flowmind doctor --ontology` flag for ontology-aware diagnostics.
- Versioned result and learning contracts (`contractVersion: 1.1`).
- Documentation for the staged ontology optimization roadmap.
