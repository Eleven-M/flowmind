# FlowMind 2.0.3

FlowMind 2.0.3 is the open-source readiness release for the 2.0 line.

## Highlights

- Added GitHub CI and npm provenance release workflow.
- Added `SECURITY.md`, `SUPPORT.md`, `CODE_OF_CONDUCT.md`, a security model, a skills catalog, and a provider adapter guide.
- Added configuration-free demo scenarios for log audit, code review, and guarded workflow review.
- Added Chinese integration documentation.
- Added private local JSON writes for FlowMind config, task, workflow, scene, and Codex workspace state.
- Development dependency auditing now resolves to zero known vulnerabilities with updated tooling and a `minimatch` override.

## Safety

- Runtime support remains Node.js 18 and newer.
- Contributor tooling is validated on Node.js 20.19+ and Node.js 22.
- Files that may contain credentials or workflow state are written with private permissions on POSIX filesystems.
- Release package contents now include docs, release notes, security/support docs, and the demo GIF.

## Verification

- `npm run quality`
- `npm audit`
- `npm pack --dry-run`
- `node bin/flowmind.js demo log-audit --json`
- `node bin/flowmind.js demo code-review --json`
- `node bin/flowmind.js demo workflow --json`

## Upgrade Status

- Current npm target: `flowmind@2.0.3`
- Open-source governance and release automation are ready.
- Configuration-free demos are available before provider setup.
