# FlowMind 2.0.0

FlowMind 2.0.0 turns the project into a stronger workflow control plane: it now combines multi-cloud service governance, guarded execution, resumable workflow history, and provider-aware rollback previews in one local agent surface.

## Highlights

- Multi-cloud governance: audit, diagnosis, and guarded policy changes across Alibaba Cloud MSE, Huawei Cloud CSE, and Baidu Cloud MSE/CSM
- Resumable workflows: local execution history, step-level resume, and workflow history listing through MCP
- Provider-aware rollback: rollback strategy previews are shown before governance mutations are approved
- Guarded execution: dry-run approval tokens and allowlisted steps still control every executable workflow
- Operator-ready UX: the homepage and release checks now describe the 2.0 surface more clearly for users and package readers

## Safety

- Governance write operations still require explicit preview and approval
- Workflow resume reuses the recorded execution chain and approval token before continuing
- Delete operations remain excluded from the first service-governance release
- Unsupported or unconfigured cloud providers remain read-only until mappings are added
