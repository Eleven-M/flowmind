# FlowMind 2.0.2

FlowMind 2.0.2 completes the workflow-history polish pass by making recorded guarded workflows easier to inspect and resume.

## Highlights

- `flowmind workflow-history --status <status>` filters recorded workflow executions by status.
- `flowmind workflow-history --resumable` shows only executions that can continue from a failed or unfinished step.
- MCP `flowmind_workflow_history` now accepts the same `status` and `resumable` filters.
- Workflow execution records now persist `resumable` state for direct filtering.
- Open-source maintenance now includes CI, provenance release workflow, security/support docs, skills catalog, provider adapter guide, and configuration-free demo scenarios.
- Local FlowMind state writes now use private permissions on POSIX filesystems for config, learning, task, workflow, scene, and Codex workspace state.

## Safety

- Approval tokens are still removed from public workflow-history output.
- Resume still requires the original reviewed approval token.
- Filters only inspect local history and do not execute workflow steps.
- Configuration files and local workflow state should still be treated as sensitive and kept out of source control.
