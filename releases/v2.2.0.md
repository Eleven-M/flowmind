# FlowMind 2.2.0

FlowMind 2.2.0 ships neutral, self-descriptive defaults for all built-in MCP server aliases ahead of broader distribution.

## Changed (Breaking)

- Built-in MCP server aliases and workflow/report provider keys now use neutral defaults. Defaults are only fallbacks: pin your existing aliases via `resources.*.mcpServer` in your config package to keep current setups working.
- Workflow and report adapters moved to `core/providers/automation/` (`flow-adapter.js`, `report-adapter.js`).
- Browser extension default host permissions now use `example.com` domains.

## Changed

- Docs, config package example, and test fixtures use generic sample identifiers only.

## Migration

If your config or resource bindings relied on the previous default aliases, set the explicit `mcpServer` values in your `flowmind-config-package` import, then re-run:

```bash
flowmind doctor
```

## Verification

```bash
npm test -- --runInBand
npm run package:check
```
